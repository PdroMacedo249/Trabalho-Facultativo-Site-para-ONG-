# 🌐 ONG Esperança Viva - Plataforma Web (SPA)

Aplicação web desenvolvida para a **ONG Esperança Viva**, focada na apresentação de causas sociais, captação de voluntários e transparência institucional.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação focada em acessibilidade e SEO.
- **CSS3 Moderno:** Layout responsivo utilizando Flexbox, CSS Grid e variáveis globais (`:root`).
- **JavaScript (Vanilla):** Lógica para arquitetura Single Page Application (SPA), manipulação do DOM e persistência no `localStorage`.

---
